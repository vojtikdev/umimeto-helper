Response efficiency

No chat history or full-page text is sent. Repeated answers reuse a bounded page-session cache. Reasoning models may spend output tokens internally; raise the cap if answers are cut off.

Image efficiency

Pictures are resized locally, converted to JPEG, and previewed before sending. Low detail may miss small text. Image token costs vary by model; the text estimate excludes image tokens. These controls affect newly captured images; Rescan to reload the exercise.

    Quick help
    
            
    
              How do I use the extension?
              
    
                Connect a model in Models, then open an Umíme exercise and check
                the captured text. Press Ask AI. Pin Umíme Helper using Chrome’s
                Extensions menu for quick controls.
              
    
            
    
            
    
              Keyboard shortcuts
              
    
                Option + Shift + U on macOS (Alt + Shift + U elsewhere) toggles
                the panel. Escape minimizes a focused panel. Customize shortcuts
                at chrome://extensions/shortcuts if the default conflicts.
              
    
            
    
            
    
              No panel or question detected?
              
    
                Refresh the exercise after installing or updating. Check
                Chrome’s extension site access. Use Rescan, select text on the
                page and choose Use selection, or adjust Detection selectors.
              
    
            
    
            
    
              API errors, limits or local servers
              
    
                Use Test connection in Models. Rejected key: verify the key and
                model access. Rate limit: wait for the displayed cooldown and
                check quota. Local model: start its server and allow the
                extension origin if the server blocks it. Native APIs require an
                OpenAI-compatible gateway.
              
    
            
    
            
    
              What does Stop do?
              
    
                Stop cancels the browser request and pauses auto-answer in that
                tab. Your provider may continue processing or charge for a
                request it already received. There are no silent retries.
              
    
            
    
            
    
              Privacy and removal
              
    
                Keys are saved locally without encryption and are not exposed to
                webpage scripts. Prompts go only to the configured provider.
                Answers are cached in page memory and disappear on refresh;
                Clear session answers removes them sooner. Remove a model to
                delete its saved key. Uninstalling removes extension settings.
                API host permissions can be managed in Chrome’s extension
                settings.
